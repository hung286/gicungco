Bước 1 — Tải file Word đề thi

File đề soạn theo định dạng chuẩn: PHẦN I/II/III/IV, mỗi câu bắt đầu bằng Câu N., phương án A. B. C. D., kết thúc mỗi câu bằng Đáp án: ... (câu Đúng/Sai ghi dạng ĐSSS hoặc SDSD).
💡 Chưa có file Word mẫu? Tải ngay mẫu chuẩn để trải nghiệm thử:
Tải File Đề Mẫu (.docx) Tải File Tiêu Đề (.docx)
File tiêu đề đề thi
Tên trường, tên kỳ thi, thời gian...
(không bắt buộc)
File đề (ngân hàng câu hỏi) *
Gồm các phần I, II, III, IV
(bắt buộc tải lên)

Bước 2 — Tùy chọn trộn đề thông minh

Phần I: trộn câu + phương án · Phần II, III: trộn câu · Phần IV (tự luận): giữ nguyên vị trí.
