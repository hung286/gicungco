Nhập danh sách học sinh, câu hỏi và tùy chỉnh âm thanh — mọi thứ lưu trên máy này.
Mẹo: dùng file mẫu Excel/Word trong tab Học sinh và Câu hỏi. File mẫu: Mau_Excel_danh_sach_hoc_sinh.xlsx, Mau_Word_nhap_cau_hoi_game.docx.
Thả file Excel vào đây hoặc bấm để chọn
Các cột: Họ tên | Lớp | Link ảnh (.xlsx)
Link ảnh được tự động chuẩn hóa: Google Drive (/file/d/ID/view), Dropbox (?dl=0) và link ảnh trực tiếp. Nếu ảnh lỗi, hệ thống dùng avatar chữ cái.
Chưa có học sinh.
Thả file Word vào đây hoặc bấm để chọn
3 dạng chuẩn của Bộ: nhiều lựa chọn · đúng/sai · trả lời ngắn (.docx)
Công thức gõ dạng LaTeX trong $...$ (VD: $x^2+2x+1=0$). Ảnh chèn trực tiếp trong Word sẽ tự đính kèm vào câu hỏi. MathType: chuyển thành ảnh hoặc LaTeX trước khi nhập.
Câu đúng/sai: ghi đáp án gọn Đáp án: SDSS — mỗi ký tự ứng với mệnh đề a, b, c, d (Đ=đúng, S=sai).
